# hzip 功能清单（当前版本全景）

> **这份文件回答一件事**：当前版本「已经有什么功能、还缺什么功能」。
> 它讲的是**产品能力**（用户能做什么），**不是** Cargo 编译期的 feature 开关（那部分见 [附录 B](#附录-bcargo-feature-对照不是本清单主体)）。
>
> - 基线：workspace **0.2.0** · 对齐 2026-10-17 的工作树（含当日尚未提交的改动：多分区镜像写回、进度窗输出区折行/大框圆角、行内图标几何、gpui-kit 0.7.3）。
> - **唯一事实来源是代码**。本清单逐条对照过 `crates/*/src` 与测试；凡「未实现」都能在代码里指出缺失点或拒绝键。
> - 想快速找缺什么：全文搜 `[ ]`（未实现）与 `[~]`（有边界/受限）。

## 0. 图例

| 标记 | 含义 |
|---|---|
| `[x]` | 已实现且可用 |
| `[~]` | 已实现，但有括号里写明的边界/限制 |
| `[ ]` | **未实现**（代码里没有实现点，或有稳定拒绝键） |
| `[R]` | 只读格式（读支持、写不支持） |

## 1. 档案格式（压缩包）

- **zip**
  - `[x]` 读：条目、目录树、按条目读、提取、逐条目 CRC 校验；Stored/Deflated 直读，加密条目与 bzip2/zstd/deflate64 走临时缓冲
  - `[x]` 写：创建（zip64）
  - `[~]` 追加：仅当输出目标是普通文件（其他 Sink 明确拒）
  - `[~]` 编辑：重写整档 + 原子替换（未命中条目原样拷贝，压缩字节/权限/时间不重编）
  - `[x]` 加密读：ZipCrypto、AES；`[x]` 加密写：ZipCrypto、AES-128/192/256
  - `[x]` 分卷读；`[x]` 分卷写（两遍法）
  - `[x]` 符号链接（读+写）；`[x]` unix mode / mtime 保留
  - `[x]` 读方法：store / deflate / deflate64 / bzip2 / zstd（另含 AES 封装）
  - `[ ]` 固实打包、档案注释；`[ ]` 方法 14（LZMA）与 PPMd（98）解码（前者与本仓 xz2 的 native 库冲突而关闭，后者 zip crate 无 ppmd feature）；`[ ]` salvage 模式不解密加密条目
- **7z**
  - `[x]` 读（含 BCJ2 解码）、`[x]` 写（LZMA2）、`[x]` 编辑（重写）
  - `[x]` 加密写 AES-256（`[S]` aes feature，默认开），可**头加密=加密文件名**；`[x]` 头加密读
  - `[x]` 分卷读
  - `[ ]` 分卷写（`SplitSink` 已写好但未接）、追加、固实打包、BCJ2 自组装编码、注释
- **tar**（GNU / ustar / pax / v7）
  - `[x]` 读（含 GNU 稀疏头与 1.0 pax 稀疏区间还原）、`[x]` 写、`[~]` 追加（仅**裸 tar**，尾零块截断法）
  - `[x]` 符号链接/硬链接（硬链接落地为空文件）、mode/mtime、稀疏落盘
  - `[ ]` 编辑、加密、分卷
- **单文件流 gz / bz2 / xz / zst**
  - `[x]` 读、`[x]` 写（单流）、mtime 写入
  - `[~]` 只能写普通文件内容（目录/符号链接明确拒）；`[ ]` 编辑、加密、分卷
- **rar** `[R]`
  - `[x]` 读 rar4/rar5、多卷、固实、AES-256
  - `[ ]` 写/追加/编辑（设计上永不做）；`[~]` 不支持 stdin/流源
- **cpio** `[R]`（newc / crc / odc / bin）
  - `[x]` 读、符号链接目标（≤4 KiB）
  - `[ ]` 写；`[ ]` hardlink 重建
- **组合档案与嵌套**（`.tar.gz`、`.cpio.gz`、档案里的内层档案/镜像）
  - `[x]` 读：组合链自动解层、内层延迟展开、嵌套会话逐层进入
  - `[x]` 写：CLI `--format tar.gz|tar.bz2|tar.xz|tar.zst`（两遍法，产物原子替换）
  - `[~]` GUI 压缩对话框只提供 7 种单格式（组合格式界面屏蔽）；`[~]` 组合链**写回**（改 `.qcow2.gz` 里的文件）未做

## 2. 磁盘镜像与卷

- **容器**
  - **raw / img / dd**
    - `[x]` 读 + `[x]` 写（覆盖写 / 就地写）；`[x]` MBR/GPT/裸文件系统三种形态自动判别
    - `[ ]` 创建镜像、扩容、快照、加密卷
  - **qcow2**（v2/v3，大端魔数）
    - `[x]` 读：稀疏、压缩簇（zlib/zstd）、L1/L2、refcount
    - `[x]` 写：簇分配与 refcount 由上游承担，提交只回放脏块
    - `[~]` 脏/损坏标志 → 只读；`[ ]` 加密卷（连读都不支持）、外部数据文件、扩展 L2 表、backing 父文件链
    - `[ ]` 创建镜像、扩容、快照
  - **vmdk**
    - `[x]` `monolithicSparse` 读 + 写；`[R]` `streamOptimized` 只读
    - `[~]` `uncleanShutdown` → 只读
    - `[ ]` `monolithicFlat` / `twoGbMaxExtentSparse|Flat`（VMware 分卷稀疏）/ `vmfsSparse` / 快照 delta / 描述符损坏 —— 均按稳定键拒绝
- **分区层**
  - `[x]` MBR / GPT 探测；GPT 分区名优先、无标签显示「分区 N」；类型列（MBR 类型字节 / GPT GUID 名）
  - `[x]` 损坏分区表降级为「未知卷」+ 提示；无分区表 → 整盘当一个卷
  - `[x]` 多分区镜像：每个分区一个顶层行，卷内条目带「分区行名/」前缀
- **文件系统驱动**
  - **ext4/ext3**
    - `[x]` 读（inode/目录树/符号链接目标/mtime/mode）、写（替换内容/删除/追加/改名/建目录）、JBD2 日志
    - `[~]` 卷内有未重放日志且未获同意 → 只读
    - `[ ]` 新建符号链接、修改 mode（`Change` 契约里没有这两类变体）
  - **FAT12/16/32**
    - `[x]` 读（LFN + 8.3、CJK）、写（五类变更）
    - `[~]` 无符号链接、无 POSIX mode、mtime 仅 2 秒精度；`[ ]` 单文件 >4 GiB
  - **NTFS**
    - `[x]` 读（UTF-16→UTF-8，有损名计数）、写（临时镜像 + 逐块比对回设备，提交前设备不动）
    - `[~]` 休眠卷 / 脏日志 → 只读
    - `[ ]` WOF/EFS/LZNT1/稀疏内容、每目录 >64 个索引块、跨目录搬目录
  - **XFS**（v4/v5）
    - `[x]` 读、写（五类变更，日志化写）；`[~]` 脏日志只在内存重放（不落盘）
    - `[ ]` realtime / reflink / B+tree fork / 外部日志卷
- **写回语义**
  - `[x]` 覆盖写（默认）：改动先落覆盖层，**提交时只回放脏块**，提交前原档字节不变
  - `[x]` 就地写：`FileDevice::open_rw` 直写（内核对三模式均支持）
  - `[x]` 提交前逐分区自检（audit）；自检不过 → 整体放弃
  - `[~]` 提交回放中途失败 = 部分提交（如实报错并记日志，不谎报原子）
  - `[x]` 多分区变更**按分区归集**：id 型按投影 id 区间、名字型按「分区行名/」前缀；隔壁分区逐字节不动
  - `[~]` 跨分区改名 → 拒绝
  - `[ ]` GUI 设置页「写回方式」三态开关（覆盖写/就地写/只读）——内核支持，界面未接
  - `[ ]` 镜像创建/格式化、扩容、快照、加密卷、多 extent VMDK

## 4. 编辑

- `[x]` 档案内变更五类：替换内容、删除、追加文件、建目录、改名（zip/7z 重写整档 + 原子替换，保未命中条目原样字节）
- `[x]` 卷容器内同样五类：就地写（覆盖层暂存 → 提交回放），多分区按分区归集
- `[x]` **外部编辑器写回**：物化到复制区 → `FileWatch`（500 ms 去抖）→ 提交 `EditBatch + Replace{entry}`；`(mtime_ns,len)` 去重、同档案在飞串行、结束后补提交
  - `[~]` 嵌套会话 / 非可编辑格式：**不提交**，保存时如实告知
  - `[~]` FAT 等粗粒度时间戳卷上「同长度 + 同一时间片」的连续保存可能漏一次（已记录取舍）
- `[ ]` 加密档案的编辑提交（添加/删除/粘贴）——挂账
- `[ ]` 档案注释编辑（zip/7z 写侧拒绝注释）
- `[ ]` 撤销/重做（无 undo 栈）
- `[ ]` 批量重命名（仅单条目行内改名）

## 5. 压缩 / 解压 / 转换 / 校验

- **压缩**
  - `[x]` 格式：GUI 7 种单格式（zip/7z/tar/gz/bz2/xz/zst）；CLI 另有 `tar.gz|tar.bz2|tar.xz|tar.zst`
  - `[x]` 级别 6 档（store/fastest/fast/normal/maximum/ultra）、方法（zip=Deflate；7z=LZMA2；gz/bz2/xz/zst 各自唯一编码器，面板按格式能力门控）
  - `[x]` 线程数、7z 字典大小、分卷（`[x]` zip / `[ ]` 7z）、排除 glob（目录命中剪枝）、排除隐藏文件、跟随符号链接、保留元数据、完成后校验、尽力而为
  - `[x]` 加密：zip 四方案 / 7z AES-256；7z 头加密（不加密文件名开关）
  - `[~]` 追加：zip（`Sink::File`）与裸 tar 可用；7z 无追加
  - `[ ]` 7z 固实、7z 分卷写、档案注释
  - `[x]` 工程性：小文件并行预读（≤4 MiB，写入序恒定）、大文件流式 1 MiB、组合格式两遍法、失败自动清理半成品
- **解压**
  - `[x]` 目标目录（默认档案所在目录，自动创建）、智能解压（多顶层自动包一层目录）
  - `[x]` 冲突五策略：询问 / 覆盖 / 跳过 / 重命名 / 仅更新（`Ask` 支持「应用到全部」）
  - `[x]` 符号链接四策略：`deny-escape`（默认）/ `deny-all` / `flatten` / `skip`（`[S]` 设置或 `--symlink`）
  - `[x]` 条目筛选（按名）
  - `[~]` 文件名编码（自动/GBK/Big5/SJIS/EUC-KR/CP1252/UTF-8）：选项已贯通到服务层，但**名字重映射尚未接线**——当前只把低置信名字标为「可疑编码」，不改名解压
  - `[x]` 尽力而为（仅校验/密码/格式类错误可累积，安全与配额类一律立即失败）
  - `[x]` 磁盘余量预检（按声明大小 ×1.05）、密码预热（避免解到一半才问）
  - `[x]` 属性恢复：mtime、unix mode、只读位、目录 mtime 延后统一恢复
  - `[ ]` 解压后删除源档案（`delete_after` 配置/`--delete` 均未接线：前者未消费、后者仅告警）
- **校验**
  - `[x]` 逐条目 CRC 完整性测试（CLI `t`，GUI 工具菜单）；镜像 = 各分区 audit
  - `[x]` 压缩后自动校验（`verify_after`，默认开；分卷按卷集装配）
- **格式转换**（`cv`）
  - `[x]` 逐条目流式转写（不落盘），支持目标格式的写能力/方法/加密白名单
  - `[~]` 单文件流目标只接受单条目源；`[ ]` CLI 转换无密码通道
- `[ ]` 断点续压 / 断点续解

## 8. 安全与边界防御

- `[x]` 条目名净化：绝对路径 / UNC / 盘符 / `..` 不抵消 / 控制字符 / Windows 22 个保留设备名 / 段尾空格与句点；`\\?\` 长路径；属性测试断言「永不逃逸」
- `[x]` 符号链接策略四档 + 「已登台账目录下」组合攻击检查（不可配置的铁律）
- `[x]` 压缩炸弹防线：单条目上限 32 GiB / 总量 128 GiB / 压缩比 200 / 条目数 1e6 + 磁盘余量预检；`[ ]` 这些上限**暂不可配**（`[security].max_*`/`min_free_disk_pct` 配置节未接线，恒用默认值；`[security].symlink` 已接线，GUI 解压面板使用）
- `[x]` 密码处理：全程 `Zeroizing`、Debug 脱敏、日志不落明文、最多 3 次重试、有界预检
